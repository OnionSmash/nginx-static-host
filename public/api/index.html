API Reference

The Stacklume REST API gives you full programmatic access to the Stacklume platform — inference, embeddings, vector storage, pipelines, and more.

Base URL: https://api.stacklume.cloud/v2 OpenAI-compatible REST + Streaming

Authentication

All API requests must include your API key as a Bearer token in the Authorization header.

ℹ️ Never expose your API key in client-side code. Store it as an environment variable or use our server-side SDKs.
HTTP
# Include in every request header
Authorization: Bearer sk-sl-<your_api_key>
Content-Type: application/json

Chat Completions

POST /v2/chat/completions Create a chat completion

Send a conversation and receive an AI-generated response. OpenAI API compatible.

from stacklume import Stacklume

client = Stacklume(api_key="sk-sl-...")

response = client.chat.completions.create(
    model="stacklume/llm-ultra-v2",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "What is the capital of France?"}
    ],
    max_tokens=512,
    temperature=0.7,
)

print(response.choices[0].message.content)

Request Parameters

ParameterTypeRequiredDescription
model string required Model ID (e.g. stacklume/llm-ultra-v2)
messages array required Array of message objects with role and content
max_tokens integer optional Maximum tokens to generate. Default: 1024
temperature float optional Sampling temperature 0–2. Default: 1.0
stream boolean optional Enable SSE streaming. Default: false
top_p float optional Top-p nucleus sampling. Default: 1.0
tools array optional List of tool definitions for function calling

Embeddings

POST /v2/embeddings Create vector embeddings

Convert text, code, or multimodal content into high-dimensional vector embeddings for semantic search, clustering, or RAG.

Python
response = client.embeddings.create(
    model="stacklume/embed-v3",
    input=["Hello world", "Semantic search with AI"],
    encoding_format="float",
)

for item in response.data:
    print(f"Embedding {item.index}: {len(item.embedding)} dims")

Vector Store

✅ The Vector Store API supports hybrid search (semantic + keyword), metadata filtering, and namespaces for multi-tenant use cases.
POST /v2/vector-stores/{store_id}/query Semantic vector search

Query a vector store by embedding similarity. Supports top-k retrieval, metadata filters, and hybrid scoring.

Python
results = client.vector_stores.query(
    store_id="vs_8mK3nP2qTw",
    query="How does retrieval-augmented generation work?",
    top_k=5,
    filter={"category": {"$eq": "docs"}},
    include_metadata=True,
)

for match in results.matches:
    print(match.score, match.metadata["text"])

Error Handling

Stacklume uses standard HTTP status codes. All errors return a JSON body with error.type, error.message, and optionally error.param.

200OK — Request succeeded.
400Bad Request — Invalid parameters or missing required fields.
401Unauthorized — Missing or invalid API key.
429Too Many Requests — Rate limit exceeded. Retry with exponential backoff.
500Internal Server Error — Contact support if this persists.
