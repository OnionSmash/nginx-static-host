# LumeCore: run an AI workflow
curl -X POST \
  https://api.stacklume.cloud/v1/workflows/run \
  -H "Authorization: Bearer $LUMEKEY" \
  -H "Content-Type: application/json" \
  -d '{
    "workflow_id": "wf_compliance_check",
    "input": {
      "text": "Patient DOB 01/01/1980...",
      "mode": "hipaa"
    },
    "trust_score_min": 0.92
  }'

  "status": "completed",
  "trust_score": 0.97,
  "output": {...},
  "latency_ms": 84
}
Quickstart

Up in 5 Minutes

Get your first Stack Lume API call working in minutes.

Node.js 
import StackLume from '@stacklume/sdk';

const client = new StackLume({
  apiKey: process.env.LUMEKEY
});

// Run a TrustWeave verification
const result = await client.trustweave.verify({
  text: 'The Eiffel Tower is in Berlin.',
  mode: 'strict'
});

console.log(result.trust_score);  // 0.04
console.log(result.corrections);  // [{...}]
Python 
from stacklume import StackLume

client = StackLume(api_key="your-key")

# Generate synthetic data with EchoSynth
dataset = client.echosynth.generate(
    schema="customer_transactions_v2",
    count=10_000,
    privacy_level="differential",
    epsilon=1.5
)

for record in dataset.iter_records():
    print(record)

Authentication

API Keys & OAuth 2.0

All API requests must be authenticated. We support both API key and OAuth 2.0 bearer token auth.

API Key Authentication

Pass your API key as a Bearer token in the Authorization header. Keys are scoped to products, environments, and rate limits.

OAuth 2.0 / OIDC

For enterprise SSO integrations, Stack Lume supports OAuth 2.0 Authorization Code flow with PKCE, and OIDC for identity federation with your corporate IdP (Okta, Azure AD, Ping Identity).

OAuth token exchange 
POST https://auth.stacklume.cloud/oauth/token
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials
&client_id=YOUR_CLIENT_ID
&client_secret=YOUR_CLIENT_SECRET
&scope=lumecore:run trustweave:verify echosynth:generate
