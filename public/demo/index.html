Here's a clean Python example using the Stacklume SDK for streaming:
python
from stacklume import Stacklume

client = Stacklume(api_key="sk-...")

# Stream a response
with client.chat.stream(
  model="stacklume/llm-ultra-v2",
  messages=[{"role": "user", "content": "Hello!"}],
  stream=True,
) as stream:
  for chunk in stream:
    print(chunk.choices[0].delta.content, end="", flush=True)

This uses server-sent events under the hood with P50 first-token latency of ~31ms. Install with pip install stacklume.
